## ⚡ Características Principales

- **Reproductor Flotante Continuo (`AudioPlayer`):** Barra persistente con ecualizador animado y audio de muestra real.
- **Catálogo Discográfico & Spotify Embed:** Sencillos oficiales (*Cumbia Reverb*, *Surfeando en la Nieve*, *Fuego Rojo*, *Si Era Tan Listo*) con letras completas y créditos.
- **Hub Protagónico de YouTube:** Banner de suscripción rápida directa con 1 clic (`?sub_confirmation=1`), video destacado, clips y shorts.
- **Tarjetas Interactivas de Integrantes:** Con fotos en alta resolución, banderas (🇨🇴 🇦🇷 🇻🇪), biografía y equipamiento (*gear*).
- **Gira & Fechas de Concierto:** Calendario en vivo con estados de boletos (*Sold Out*, *Últimas Entradas*, *Preventa*).
- **Modal de Contratación Express:** Cotizador para festivales y eventos que genera automáticamente el mensaje listo para enviar por WhatsApp o correo.
- **Tienda Oficial de Merchandising:** Camiseta y vinilo splatter con selector de talla y pedidos directos vía WhatsApp.
- **Electronic Press Kit (EPK) & Rider Técnico:**
  - Stage Plot interactivo (distribución de los 5 músicos en tarima).
  - Input List para ingenieros de consola FOH (14 canales, micrófonos y Phantom +48V).
  - Especificaciones de monitoreo In-Ear (IEM).
  - Descargas directas de Rider PDF, EPK y fotos de prensa.
- **SEO & Datos Estructurados:** Schema.org `MusicGroup` y metaetiquetas Open Graph / Twitter Cards.

## 🛠️ Tecnologías

- **Empaquetador & Dev Server:** [Vite](https://vitejs.dev/)
- **Frontend:** Vanilla JavaScript (ES Modules)
- **Estilos:** Vanilla CSS con sistema de variables neón, glassmorphism y diseño responsive
- **Efectos:** Canvas dinámico interactivo con osciloscopio de ondas de reverberación

## 🚀 Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/rubenoliveros/cumbia-reverb-web.git
   cd cumbia-reverb-web
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor local de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
   Los archivos estáticos optimizados se generarán en la carpeta `dist/`.
